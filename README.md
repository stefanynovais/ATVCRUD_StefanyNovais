# 🌷 APP CRUD no React Native com APIs REST utilizando Fake API (Json-Server)

✨ O objetivo dessa API Rest desenvolvida em **React Native** é a criação, edição, exclusão e filtragem de usuários.


---

## 🚀 Tecnologias utilizadas
- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/) (para rodar o app)
- FlatList

---

## 🛠 Como rodar o projeto
1️⃣ Clone este repositório
```bash
git clone https: //github.com/seuusuario/nome-do-repo.git]((https://github.com/stefanynovais/ATVCRUD_StefanyNovais.git))
  ```
2️⃣ Acesse a pasta
```bash
cd nome-do-repo
  ```
3️⃣ Instale as dependências
```bash
npm install
  ```
4️⃣Para executar no **ExpoGo**
```bash
npx expo start
  ```
